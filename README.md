# مكتبة الحكايات / Story Library

موقع ثابت لقصص الأطفال بالعربية والإنجليزية، يعمل على ⁦GitHub Pages⁩ بدون خادم.

## الملفات

- `index.html`: صفحة عرض الكتب. مفتوحة لأي زائر.
- `admin.html`: صفحة رفع الكتب وحذفها. تحتاج اسم مستخدم وكلمة مرور.
- `books.json`: قائمة الكتب. تحدّثها لوحة الرفع تلقائيًا.
- `site-config.json`: اسم الموقع ونصوص الصفحة الرئيسية والاقتباسات وإعدادات المظهر.
- `site-config.js`: تحميل إعدادات الموقع وتطبيق النصوص والثيم بأمان على الصفحات العامة.
- `books/`: ملفات ⁦PDF⁩ للكتب.
- `covers/`: صور الأغلفة.
- `style.css` و `i18n.js`: التصميم والنصوص العربية والإنجليزية.

## النشر على GitHub Pages

1. أنشئ مستودعًا على ⁦GitHub⁩ (مثلًا `stories-site`) وارفع إليه كل هذه الملفات.
2. من ⁦Settings ← Pages⁩ اختر ⁦Deploy from a branch⁩، ثم الفرع `main` والمجلد `/ (root)`.
3. بعد دقيقة تقريبًا يظهر الرابط: `https://USERNAME.github.io/stories-site/`

## مفتاح الرفع (مرة واحدة)

1. على ⁦GitHub⁩: ⁦Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token⁩.
2. في ⁦Repository access⁩ اختر ⁦Only select repositories⁩ ثم مستودع الموقع فقط.
3. في ⁦Repository permissions⁩ اجعل ⁦Contents⁩ على ⁦Read and write⁩.
4. انسخ المفتاح.

## أول دخول إلى صفحة الرفع

افتح `/admin.html`. في أول مرة تنشئ اسم مستخدم وكلمة مرور (8 أحرف أو أكثر)، وتلصق مفتاح ⁦GitHub⁩ مع اسم حسابك واسم المستودع. المفتاح يُحفظ مشفّرًا بكلمة مرورك على هذا الجهاز فقط. بعدها تدخل في كل مرة باسم المستخدم وكلمة المرور.

على جهاز آخر تنشئ الحساب من جديد وتلصق المفتاح مرة أخرى.

## ما الذي يحمي الموقع فعلًا

الموقع ثابت، لذلك لا يوجد خادم يتحقق من كلمة المرور. الحماية الحقيقية هي مفتاح ⁦GitHub⁩: بدونه لا يستطيع أحد الرفع أو الحذف، حتى لو فتح `admin.html`. كلمة المرور تمنع أي شخص يستعمل جهازك من استعمال المفتاح المحفوظ.

لا تشارك المفتاح مع أحد، ولا تسجّل الدخول من جهاز مشترك.

## ملاحظات

- بعد كل رفع يحتاج ⁦GitHub Pages⁩ نحو دقيقة ليظهر الكتاب.
- افتح الموقع دائمًا من رابط الاستضافة. فتح `index.html` مباشرة من الجهاز لن يحمّل قائمة الكتب.
- العنوان والنبذة يمكن كتابتهما بالعربية أو الإنجليزية أو بالاثنتين. يظهر الموقع النص المناسب للغة التي يختارها الزائر.
- من لوحة الإدارة، يتيح قسم «إعدادات الموقع» تعديل النصوص العربية والإنجليزية والاقتباسات والألوان والخطوط. تُحفظ الإعدادات عبر GitHub Contents API في `site-config.json`، ثم تظهر بعد تحديث GitHub Pages.
- إعدادات المظهر تعرض أنماط ألوان جاهزة ومتناسقة بدلًا من اختيار كل لون منفردًا؛ اختيار النمط يحدّث المعاينة ويحفظ لوحة ألوانه مع بقية إعدادات الثيم.

## حقول القصة الاختيارية

تحافظ قائمة `books.json` على الحقول الحالية (`id` و`title` و`titleEn` و`summary` و`summaryEn` و`age` و`file` و`cover`). يمكن إضافة حقول اختيارية إلى أي سجل لعرض محتوى إضافي في صفحة القصة:

- `category` و`categoryEn`: اسم التصنيف بالعربية والإنجليزية. يمكن إدخالهما من لوحة الإدارة؛ وعند غيابهما يستخدم الموقع الفئة العمرية للتصفية.
- `storyText` و`storyTextEn`: نص القصة باللغتين.
- `images`: قائمة بمسارات صور معرض القصة.
- `audio` و`audioEn`: مسار الملف الصوتي بالعربية والإنجليزية.

تظهر أقسام PDF والنص والصور والصوت فقط عند وجود بياناتها. الحقول الاختيارية لا تمنع قراءة السجلات القديمة.
